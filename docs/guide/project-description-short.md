# 司南 Sinan - 跨浏览器书签同步管理系统（300字版）

## 项目介绍

司南 Sinan 是一个现代化的跨浏览器书签管理系统，通过浏览器插件 + 云端服务架构，解决多浏览器书签割裂和查找困难的痛点。

## 核心痛点

1. **多浏览器割裂**：Chrome 和 Edge 书签无法互通，换浏览器就找不到之前收藏的内容
2. **查找困难**：书签越来越多，想找特定网站很麻烦，尤其是中文网站
3. **团队共享不便**：无法便捷地与团队成员分享有用的资源链接

## 技术架构

- **后端**：Node.js + PostgreSQL + Redis，提供 RESTful API 和 WebSocket 实时同步
- **前端**：Chrome/Edge 扩展 + Vue.js 管理界面

## 主要功能

1. **跨浏览器同步**：Chrome、Edge 等主流浏览器实时同步
2. **智能搜索**：支持关键词、拼音、首字母搜索（如搜"ryf"找到"阮一峰"）
3. **团队分享**：一键分享书签集合，支持权限管理
4. **快捷操作**：输入框直接搜索（bm + 关键词），提升使用效率

## 适用场景

- **个人用户**：开发者、设计师、学生管理专业资源
- **团队协作**：共享项目文档、工具链接、行业资源
- **企业应用**：构建知识管理体系，新人培训资源库

司南让书签管理从杂乱变有序，让知识收藏真正产生价值。
