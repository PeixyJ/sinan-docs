# 司南 Sinan - 跨浏览器书签同步管理系统

## 项目是什么？

司南 Sinan 是一个现代化的跨浏览器书签管理系统。它通过浏览器插件 + 云端服务的架构，实现了 Chrome、Edge 等主流浏览器之间的书签实时同步，并在此基础上提供了智能搜索、团队分享、快捷操作等增值功能。

简单来说，它就像是你的"书签云盘" + "书签管家"，让你在任何浏览器、任何设备上都能访问和管理自己的书签收藏。

## 解决了什么痛点？

### 1. 多浏览器书签割裂问题
很多人因为工作需要或个人习惯，会同时使用 Chrome 和 Edge 浏览器。但两个浏览器的书签是独立的，在 Chrome 收藏的内容，Edge 里看不到，反之亦然。每次换浏览器都要重新搜索，非常影响效率。

### 2. 书签查找困难
随着收藏内容越来越多，想找到之前保存的某个网站变得很困难。尤其是中文网站，你可能记不清当初是用中文名收藏的，还是用网站域名收藏的。

### 3. 团队资源共享不便
团队成员各自收藏了很多有用的资源，但缺乏一个便捷的分享机制。新人入职需要了解常用网站，老员工要分享经验资源，都很麻烦。

### 4. 插件管理混乱
浏览器装了十几个插件，每次要用的时候都要在密密麻麻的图标里找半天，影响工作效率。

## 技术架构

### 后端技术栈
- **框架**: Node.js + Express/Koa
- **数据库**: PostgreSQL/MySQL (存储用户数据和书签信息)
- **缓存**: Redis (提升查询性能)
- **认证**: JWT + OAuth2.0 (支持 GitHub/Google 登录)
- **API**: RESTful API + WebSocket (实时同步)

### 前端技术栈
- **浏览器插件**: Chrome Extension API / Edge Extension API
- **Web 管理端**: Vue.js/React + Ant Design
- **搜索引擎**: 自研拼音搜索算法 + Elasticsearch

### 核心技术特点
- **实时同步**: 基于 WebSocket 的实时数据推送
- **智能搜索**: 支持中文分词、拼音转换、首字母匹配
- **数据安全**: 端到端加密，用户数据安全存储
- **高性能**: 毫秒级响应，支持万级书签管理

## 核心功能

### 1. 跨浏览器同步
- 支持 Chrome、Edge、Firefox 等主流浏览器
- 实时同步，无需手动刷新
- 支持书签文件夹结构完整同步
- 冲突自动处理机制

### 2. 智能搜索系统
- **全文搜索**: 搜索书签标题、URL、描述
- **拼音搜索**: 输入 "zhihu" 找到 "知乎"
- **首字母搜索**: 输入 "ryf" 找到 "阮一峰"
- **模糊匹配**: 容错能力强，即使输错也能找到

### 3. 团队协作功能
- **书签集分享**: 一键生成分享链接
- **权限管理**: 可设置只读/可编辑权限
- **批量导入导出**: 支持 HTML/JSON 格式
- **团队空间**: 创建团队共享书签库

### 4. 效率提升工具
- **快捷键支持**: 自定义快捷键快速访问
- **命令框搜索**: 输入 "bm 关键词" 快速搜索
- **智能推荐**: 基于使用频率推荐常用书签
- **标签管理**: 多维度组织管理书签

## 适用场景

- **设计师**: 收藏设计灵感、素材网站、配色工具

### 团队使用场景
- **开发团队**: 共享开发文档、工具链接、最佳实践
- **产品团队**: 收集竞品信息、用户反馈、行业报告
- **运营团队**: 管理推广渠道、数据平台、素材库
- **创业团队**: 统一管理常用 SaaS 工具、合作资源

### 企业级应用
- **知识管理**: 构建企业知识库入口
- **新人培训**: 快速熟悉公司常用系统和资源
- **项目协作**: 项目相关资源集中管理
- **效率工具**: 提升团队整体工作效率

## 产品优势

1. **零学习成本**: 安装插件即用，界面简洁直观
2. **数据安全**: 支持私有化部署，数据完全掌控
3. **轻量高效**: 插件体积小，不影响浏览器性能
4. **持续更新**: 根据用户反馈持续优化功能
5. **开源友好**: 部分核心代码开源，接受社区贡献

## 为什么选择司南？

不同于传统的书签管理工具，司南不仅解决了基础的同步问题，更是从中国用户的实际使用习惯出发（比如拼音搜索），提供了一整套提升信息管理效率的解决方案。无论你是个人用户还是团队用户，司南都能帮你把零散的网络资源变成有序的知识体系，让每一次收藏都产生价值。
